# 연구원 통합 ERP

연구기관의 연구행정 업무를 하나로 묶은 단일 페이지 웹앱입니다. AI 기능이 들어 있습니다.

## 모듈
| 메뉴 | 기능 |
|---|---|
| 대시보드 | 진행 과제, 총 연구비, 집행률, 결재 대기 KPI · 과제별 집행률과 기간 경과율 비교 · 자동 경보 |
| 연구과제 | 과제 기본정보, 기간, 비목별 예산(인건비·학생인건비·연구활동비·연구재료비·연구수당·간접비) |
| 예산·집행 | 비목별 예산·집행·잔액 · 집행 내역 등록과 검색 |
| 인력·참여율 | 참여율 총합 100% 초과와 동시수행 과제 수(5개, 책임 3개) 점검 |
| 장비·자산 | 자산 대장, 차기 교정일 D-day 경보 |
| 전자결재 | 지출결의, 구매, 출장 기안과 승인·반려 처리 |

## AI 기능
- **AI 어시스턴트**: ERP 데이터를 도구로 직접 조회해 자연어 질문에 답합니다.
- **영수증 인식**: 영수증 사진에서 일자, 거래처, 금액, 비목을 추출해 입력 칸을 채웁니다.
- **비목 추천**: 적요와 거래처를 보고 비목과 증빙 주의사항을 제시합니다.
- **과제 현황 보고서**: 과제별 중간 점검 보고서 초안을 작성합니다.
- **이상 집행 점검**: 기간 외 집행, 분할 결제 의심, 한도 초과 등을 점검합니다.
- **결재 사전검토**: 승인 권고, 보완 요청, 반려 권고와 함께 확인할 증빙 목록을 제시합니다.

## 실행
- **claude.ai 아티팩트**: 공유 DB와 AI 기능이 모두 동작합니다.
- **`index.html`을 브라우저에서 직접 열 때**: 로컬 데모 모드로 실행됩니다(데이터는 이 브라우저에만 저장, AI 기능 없음).
